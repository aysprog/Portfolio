This is my personal portfolio website, designed to introduce my work, highlight my frontend development skills, and provide a central place to explore my projects and professional background.

The website focuses on clean design, responsive layouts, accessibility, and a smooth browsing experience.

- HTML5 – Semantic structure
- CSS3 – Styling and responsive layouts
- Tailwind CSS – Utility-first styling
- JavaScript – Interactive functionality
- Git & GitHub – Version control and project management
- GitHub Pages – Website deployment

## Getting Started

To explore the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/aysprog/Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio
   ```

3. Open `index.html` in your browser.
